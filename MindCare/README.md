# Mind Care

A student mental health support application designed to help university students track their emotional well-being, manage academic stress, and access supportive mental health resources.

## Project Overview

Mind Care is a UI/UX design project developed for the User Interface Design (HCI2011) course at Umm Al-Qura University.

## Features

- Daily mood check-ins
- Session history tracking
- Personalized condition summaries
- Motivational quotes and wellness tips
- Mental health progress tracking
- Doctor communication support
- Privacy-focused design
- Calm and student-friendly interface

## Application Pages

- Home Page
- Sign In / Sign Up
- Main Menu
- Daily Check-in
- My Condition
- Session History
- Motivation Page
- Contact Us

## Tools Used

- Canva
